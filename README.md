A complete interpreter for make.fun's tiny stack ISA v1, in one file (`main.ts`, Node 22, no dependencies): wrapping 32-bit arithmetic, signed and unsigned division, 5-bit-masked shifts, sign-extended `PUSH8`, the 256-value stack, 64-deep call stack, 256 words of memory, and all ten traps with their own exit codes. Practice set: 40 of 40 match the reference, score 1,000,000 (house baseline: 670,000).
